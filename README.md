# Fuzzy Logic, Genetic Algorithms and Swarm Algorithms (2026)

This repository has the practical material for the course **Fuzzy Logic, Genetic Algorithms and Swarm Algorithms** at **Latakia University**, Faculty of Informatics Engineering, Department of Artificial Intelligence.

Here you will find the Python code, exercises and solutions that we use in the practical sessions.

## What you will learn

- **Genetic algorithms**: how to solve a problem the way nature does. We start with random solutions, keep the good ones, mix them and change them a little, and repeat.
- **Fuzzy logic**: how to work with ideas that are not just "yes" or "no", like "a bit hot" or "very fast".
- **Swarm algorithms**: how a group of simple agents (like birds or ants) can find good solutions by working together.

## What is in this repository

- One Python file for each problem, numbered in the order we study them.
- Every file starts with a short note: the problem, how we represent the solution, and how to run the file.
- The code is short and has simple comments, so you can read it from top to bottom.

## How to run the code

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Open a terminal in the folder of the file.
3. Run the file, for example:

   ```
   python 1_graph_coloring.py
   ```

   On Mac or Linux you may need to type `python3` instead of `python`.

Most files use only the standard Python library, so you do not need to install anything else. If a file needs an extra library, install it with:

```
pip install -r requirements.txt
```

## Tips for students

- Read the problem first and try to solve it on paper before you look at the code.
- Run the code, then change it. Change a number, add a gene, remove a line, and see what happens.
- Many files use `random.seed(1)`, so everyone gets the same output. Remove this line to get new random results each time.
- If something is not clear, bring your question to the next session.

Good luck, and have fun with it!
